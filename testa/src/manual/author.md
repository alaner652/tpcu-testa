## 建立題庫與寫題目

![建立題庫與寫題目](bank-write)

1. 到 **題庫**，按 **新增題庫**（或按 `N`）。
2. 填題庫名稱與科目。
3. 選題型新增一題，輸入題目與選項。
4. 點選項旁的圓圈設為正確答案。
5. 按 **模擬作答**，用考生看到的畫面試考一次。

#### 注意

- 內容會自動儲存，不用按儲存。兩個人同時改同一份題庫時，系統會提醒。
- 發布考試時題目會被複製一份固定下來，之後再改題庫不會影響已發布的考試。

## 四種題型

| 題型 | 怎麼批改 | 設定重點 |
| --- | --- | --- |
| 單選 | 自動 | 點一個選項為正確答案 |
| 多選 | 自動 | 點多個選項為正確答案 |
| 填空 | 自動 | 可以設定多個可接受的答案 |
| 申論 | 人工、匿名 | 寫評分規準，只有評分者看得到 |

## 數學式

- 用 `$...$` 把數學式包起來，例如 `$x^2$`。
- 工具列有常用符號：次方、下標、根號、分數、積分、極限、總和、矩陣。
- 預覽和考生看到的一樣，寫完可以用 **模擬作答** 確認。

## 整理題目

| 想做的事 | 方法 |
| --- | --- |
| 複製一題 | 該題的選單選 **複製題目**，或按 `Ctrl/⌘ + D` |
| 調整順序 | 拖曳題號，或按 `Alt + ↑ / ↓` |
| 一次選多題 | 在題號卡上按住 `Ctrl/⌘` 點選 |
| 調整配分 | 用題目配分欄的 ＋ / － 調整 |

## AI 匯入題目

系統管理員開啟後，編輯題庫的畫面上方會出現 **AI 匯入**。

1. 上傳現有的考卷（.docx、.pdf 或 .txt）。
2. AI 整理成題目後，**每一題都要你確認** 才會加入題庫。
3. 匯入後請一定用 **模擬作答** 檢查答案和配分。

#### 注意

- AI 只會看到你上傳的考卷內容，不會看到任何考生資料。
