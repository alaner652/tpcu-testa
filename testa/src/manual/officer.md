## 一場考試的流程

| 時間 | 要做的事 |
| --- | --- |
| 考前一到兩週 | 建立考試、匯入名單、指派評分者 |
| 考前幾天 | 列印登入單、發布考試、確認電腦教室能連上 Testa |
| 考試當天 | 發登入單、監考、處理鎖定與補時 |
| 考後 | 結束考試、等評分完成、確認分數、公布成績 |

## 建立考試、匯入名單、發布

![建立考試](exam-create)

1. 到 **考試**，按 **建立考試**，填名稱、選題庫、開始時間與作答時間，按 **建立草稿**。
2. 點進這場考試，在 **考生** 分頁按 **匯入名單**，選 Excel 或 CSV 檔。
3. 確認可以匯入的筆數；有問題的資料會列出原因，修正後再上傳即可。
4. 到 **登入單** 分頁列印，每位考生一張，上面有准考證號與登入碼。
5. 回到 **考試** 列表，按 **發布**。發布後考生在開始時間就能進入。

#### 名單格式

| 准考證號 | 姓名 | 報考科系 |
| --- | --- | --- |
| A115-0001 | 王小明 | 資訊管理系 |

- 第一列可以是欄位標題。CSV 可以是 Big5 或 UTF-8。
- 系統會自動排座位並產生登入碼。
- 發布後還要修改設定，可以在 **⋯** 選單 **取消發布（改回草稿）**，名單會保留。

## 監考與補時

![監考與補時](exam-proctor)

1. 考試進行中打開這場考試，上方數字顯示作答中、已交卷、尚未登入的人數，點一下可以篩選。
2. **需要注意** 列出登入碼輸錯被鎖定的考生，按他那一列的 **重設登入碼**，再把新的登入單交給他。
3. 要補時，選取考生（可以多位），按 **補時**，選分鐘數並寫原因。

#### 注意

- 考生離開考試畫面會被記錄次數，顯示在他的名字旁。
- 考生斷線或換電腦，重新登入就能從原進度繼續，時間由伺服器計算。
- 所有人都交卷後，按 **結束考試**。時間到時系統也會自動收卷。

## 指派評分者

1. 在考試的 **評分** 分頁，替申論題指派一到多位評分者。
2. 每位評分者各自評分，系統取平均。

#### 注意

- 評分者看不到考生身分，也看不到彼此的分數。
- 沒有申論題的考試不需要評分者，交卷後就有分數。

## 公布成績

![公布成績](results-publish)

1. 評分完成後，到 **成績** 分頁確認分數。
2. 評分者之間差距較大的答案會被標出，需要的話可以 **重開評分**（要寫理由）。
3. 按 **公布成績**。公布後成績鎖定，不能再修改。
4. 用 **匯出 Excel** 或 **CSV** 下載成績交給學校放榜。

#### 注意

- 想讓考生自己登入查分數，在 **成績** 分頁開放考生查詢。
- 不再使用的考試可以 **封存**，封存後只能檢視，資料依系統設定的年數保留。
