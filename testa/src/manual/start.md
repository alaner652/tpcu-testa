## 教職員登入

![教職員登入](staff-login)

1. 打開 Testa，在登入頁選 **教職員**。
2. 輸入系統管理員給你的 **Email** 與 **密碼**，按 **登入**。
3. 第一次登入或密碼被重設過時，會先要求換一組自己的密碼。

#### 注意

- 這台電腦上次用哪一種身分登入，下次會自動選好。
- 忘記密碼時請找系統管理員重設，系統會給一組臨時密碼。
- 密碼連續輸錯太多次，帳號會暫時鎖定，稍後再試或請管理員協助。

## 角色與能做的事

角色是 **依單位**（例如招生組）指派的，一個人可以同時有多個角色。上方選單只會出現你的角色用得到的頁面。

| 角色 | 能做的事 |
| --- | --- |
| 負責人 | 安排考試、匯入名單、指派評分者、公布成績、管理單位成員 |
| 出題 | 建立與編輯題庫 |
| 監考 | 看考生狀態、重設登入碼、補時 |
| 評分 | 批改被指派的申論題，看不到考生姓名 |
| 系統管理員 | 管理帳號與單位、備份、系統設定；看不到考卷 |

常見的組合：

- **承辦人**：負責人＋監考
- **教師**：出題＋評分

## 畫面導覽

| 頁面 | 給誰 | 用途 |
| --- | --- | --- |
| 首頁 | 所有教職員 | 考試概況，以及接下來要做的事，例如待閱卷、要發布的考試 |
| 題庫 | 出題 | 寫題目、模擬作答 |
| 考試 | 負責人、監考 | 建立考試、名單、登入單、監考、成績 |
| 閱卷 | 評分 | 一份一份批改申論題 |
| 管理 | 系統管理員 | 總覽、帳號、單位、操作紀錄、備份、系統設定 |

## 小技巧

- 右上角的帳號選單可以切換 **深色模式**、**變更密碼**、打開這份手冊。
- 用電腦時，帳號選單裡的 **鍵盤快捷鍵** 會列出這一頁能用的按鍵，例如 `/` 搜尋、`N` 新增。
- 名單可以一次選取多位：按住一列、按住 `Ctrl`（Mac 是 `⌘`）點選，或勾選列首的方框。
- 建議使用電腦版 Chrome 或 Edge。手機可以查看與監考，但寫題目和閱卷請用電腦。
