## 第一次架設

全新的 Testa 沒有任何帳號。第一個打開網站的人會看到 **建立系統管理員** 的畫面，所以架設完成後請 **立刻** 打開網站建立管理員帳號。

- 系統管理員負責帳號與系統，看不到考卷。
- 建議至少設兩位系統管理員，避免一個人請假時沒人能處理。

## 總覽

**管理** 的第一個分頁是總覽，每天打開看一眼就好。

![總覽與操作紀錄](admin-audit)

| 區塊 | 內容 |
| --- | --- |
| 需要處理 | 備份異常、帳號被鎖定、還沒換掉臨時密碼等，旁邊有按鈕直接前往處理 |
| 目前狀態 | 在線人數、正在作答的考生、進行中與即將舉行的考試 |
| 系統 | 備份狀態、主機剩餘空間、資料庫大小、版本 |
| 最近的重要操作 | 不含一般登入與作答，點「全部紀錄」看完整操作紀錄 |

顯示「一切正常」時，不需要做任何事。

## 新增帳號並加入單位

![新增帳號](admin-create-account)

1. 到 **管理 > 使用者**，按 **新增帳號**。
2. 填 Email 與姓名。
3. 在同一個表單選要加入的單位和角色，按 **建立帳號**。
4. 畫面會顯示臨時密碼，請交給本人；對方第一次登入時會被要求更換。

#### 注意

- 人數多時用 **批次建立**：從 Excel 選取姓名與 Email 兩欄貼上，一次建立。
- 臨時密碼只會顯示這一次，關掉前請先抄下或複製。

## 管理帳號

1. 點一個人可以展開他的單位與角色，直接增減。
2. 列尾的 **⋯** 選單可以重設密碼、停用帳號。
3. 停用後的帳號才能永久刪除；刪除前會再確認一次。

#### 注意

- 一次處理多人：勾選多位後，下方會出現操作列，可以一起加入單位、停用或啟用。
- 按 `/` 可以直接搜尋姓名或 Email。

## 單位

- 單位是一群一起辦考試的人，例如招生組、教務處。題庫和考試都屬於某個單位。
- 不再使用的單位可以停用，資料會保留。

## 操作紀錄

所有敏感操作（登入失敗、重設密碼、發布考試、公布成績、還原備份等）都會留下紀錄。**紀錄只會增加，任何人都不能修改或刪除。**

1. 在搜尋框輸入姓名、Email、准考證號、單位或理由，例如 `王承辦`。
2. 需要的話，用右邊的選單只看某一種操作，並選擇時間範圍（今天、最近 7 天、最近 30 天或自訂日期）。
3. 點一筆紀錄，可以看到完整內容，包括時間、身分、對象、理由與 IP 位址。
4. 按 **匯出 CSV**，把目前篩選出來的紀錄下載成 Excel 打得開的檔案。

#### 注意

- 紅字的是失敗或重大的操作，例如登入失敗、刪除考試資料、還原備份。
- 處理申訴或稽核時，先縮小時間範圍再匯出，一次最多 10000 筆。

## 備份與還原

| 項目 | 說明 |
| --- | --- |
| 自動備份 | 每天一次，頁面會顯示 **下次自動備份** 的時間；保留天數在系統設定調整 |
| 立即備份 | 重大操作前（例如升級、公布成績前）建議先手動備份 |
| 下載 | 把備份檔另存到別的地方，主機壞掉時才救得回來 |
| 還原 | 在 **⋯** 選單，需要輸入「還原」確認；考試進行中不能還原 |

#### 注意

- 還原會讓整個系統回到那一份備份的時間點，之後的資料都會消失。
- 備份狀態顯示 **需要注意** 時，代表超過一天沒有新的備份，請通知架設的人。
- **執行紀錄** 列出最近每次備份、刪除、還原是成功還是失敗。
- **主機剩餘空間** 不到一成時會變紅，請減少保留天數或請維護人員擴充硬碟。
- 超過一個月沒有下載備份時，頁面會提醒你。請每個月下載一份，存到學校 NAS 或加密隨身碟。

## 緊急檢視

系統管理員平常看不到考卷。真的需要查看時（例如處理申訴），須由該場考試的負責人在考試頁授權 **緊急檢視**，並選擇有效時間，到期自動失效，整個過程會留在操作紀錄。

## 系統設定

不用改伺服器上的檔案，所有可調整的項目都在 **管理 > 系統設定**，每一項都有說明，旁邊也會顯示 **預設值**，改過的項目可以按 **恢復預設**。頁面上方會顯示最後由誰、在什麼時候改了什麼。

| 設定 | 用途 |
| --- | --- |
| AI 匯入題目 | 預設關閉。開啟後出題老師可以把現有試卷交給 AI 整理成題目 |
| 評分差距提醒 | 多位評分者分數差距超過這個比例時提醒負責人 |
| 備份保留天數 | 自動備份要留幾天 |
| 資料保存年數 | 封存的考試保留多久 |
| 登入保護 | 連續輸錯幾次要鎖定、鎖定多久 |

#### 注意

- 改了還沒儲存時，下方會出現 **有還沒儲存的變更**，可以儲存或放棄；直接離開這一頁會先問你。
